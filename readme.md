# 修仙之路账户管理器

一个用于管理《修仙之路》QQ 频道游戏账号的自动化面板。它会为每个账号启动浏览器会话，保存登录状态，按账号配置调度命令，并在网页面板中实时展示会话、任务、待执行命令和等待响应情况。

## 功能概览

- 多账号管理：添加、登录、登出、删除账号，并查看每个账号的会话状态。
- 自动任务调度：按配置自动执行打坐、药园、悬赏、秘境、妖兽园、幻境、钓鱼、种树、气运、背包、日常、活动、救援、采集、制符、法器、屠宗等流程。
- 实时仪表盘：展示在线账号、有效会话、待执行命令、等待响应命令和活动关注项。
- 状态与设置编辑：在账号卡片中打开状态或设置弹窗，直接修改对应字段。
- 手动命令发送：对在线账号发送临时命令。
- 会话维护：保存账号会话，并在会话临近过期时尝试自动更新。
- 调试日志：输出简洁、带颜色的控制台日志，并将日志写入 `logs/` 目录。

## 环境要求

- Windows PowerShell
- Node.js
- npm
- 可访问 QQ 频道网页的网络环境

## 安装

1. 下载或克隆本项目。
2. 在项目目录中运行：

   ```powershell
   .\install.ps1
   ```

3. 按提示安装依赖，并填写《修仙之路》所在 QQ 频道链接。

安装完成后，项目会生成或更新运行所需依赖。账号数据保存在 `accounts.dat`，不要把它提交到公开仓库。

## 启动

运行：

```powershell
.\start.ps1
```

或直接运行：

```powershell
npm run start
```

启动后打开控制台显示的地址，通常是：

```text
http://localhost:3000
```

## 使用流程

### 1. 添加账号

点击页面右上角的“添加账户”，输入账号 ID 和可选密码。

登录方式会按可用条件自动尝试：

- 已登录 QQ 的快速登录
- 密码登录
- 扫码登录

如果无法自动登录，页面会弹出二维码，扫码后程序会继续保存会话。

### 2. 配置自动任务

在账号卡片中点击“设置”，打开配置弹窗。每个模块默认独立开关，只有启用后才会参与自动调度。

建议先配置好需要启用的模块，再登录账号。登录完成后，调度器会根据配置和当前状态安排命令。

### 3. 查看或修正状态

点击“状态”可以查看当前账号状态。状态一般由程序自动维护，但在这些场景下可以手动修正：

- 初次接管账号时，需要标记当天已完成的任务。
- 游戏内状态和面板状态不一致。
- 某个任务被人工执行过，需要避免重复发送命令。

不确定状态时，可以等到每日 00:00 后重新登录，让程序从新一天开始调度。

### 4. 登录并运行

点击账号卡片中的“登录”。账号登录成功后，程序会立即注册自动任务，并根据配置发送或排队命令。

卡片上的关键计数：

- “待执行”：已经排队、等待到点执行的命令。
- “等待响应”：已经发送、正在等待游戏回复的命令。
- “活动关注”：当前需要注意的自动任务状态，例如进行中、未完成、失败或材料不足。

### 5. 更新会话

会话通常可以持续约 48 小时。程序会尝试在会话过期前自动更新。

如果自动更新失败，可以在账号在线时点击“更新会话”。如果需要清理旧会话，先登出账号，再点击“清除会话”。

### 6. 手动发送命令

账号在线后，可以在卡片输入框中输入命令并点击“发送”。如果命令可以识别为已支持类型，它会进入调度器；否则会直接发送到频道。

## 日志

日志目录：

```text
logs/
```

常见文件：

- `combined.log`：普通运行日志。
- `error.log`：错误日志。
- `debug.log`：调试日志，仅在启用 debug 时生成。

控制台日志会使用简洁的 `key=value` 格式，并带有颜色，方便快速定位账号、命令和错误原因。

启用详细调试日志：

```powershell
$env:DEBUG_LOG="true"
npm run start
```

也可以通过 `LOG_LEVEL` 指定日志级别：

```powershell
$env:LOG_LEVEL="debug"
npm run start
```

## 常见问题

### 页面没有实时更新

先确认浏览器右上方连接状态是否为已连接。如果连接断开，刷新页面或重启服务。面板通过 WebSocket 接收账号状态和命令队列更新。

### 命令一直等待响应

可能是游戏没有返回可匹配的回复、网络请求失败或账号会话异常。查看控制台或 `logs/combined.log` 中的 `command.failed`、`command.processError`、`scheduler.response.timeout` 等日志。

### 登录失败

确认频道链接正确、账号可以正常访问 QQ 频道网页，并尝试扫码登录。必要时登出后清除会话，再重新登录。

### 账号数据损坏

程序保存账号数据时会生成备份文件 `accounts.dat.bak`。如果主文件无法读取，会尝试从备份恢复。

## 开发

构建 TypeScript：

```powershell
npm run build
```

启动开发运行：

```powershell
npm run start
```

主要目录：

- `src/server/`：HTTP、WebSocket、账号和实例运行时。
- `src/commands/`：命令识别、响应处理和调度效果。
- `src/public/`：前端账号面板。
- `src/utils/`：日志、时间、字段解析等工具。
- `scripts/`：安装和提交辅助脚本。

## 反馈问题

反馈时请尽量提供：

- 出问题的任务类型。
- 控制台或 `logs/combined.log` 中相关日志。
- 当时卡片上的“待执行”和“等待响应”数量。
- 复现步骤。
