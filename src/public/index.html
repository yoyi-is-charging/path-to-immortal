使用指南

首次使用

  1. 点击 添加账户，填写账号 ID 和可选密码。
  2. 点击 设置，启用需要自动执行的项目。
  3. 点击 登录，等待会话建立并开始调度。

账号卡片

待执行 是已经排队、等待到点发送的命令；等待响应 是已经发送、正在等待游戏回复的命令。两个数字会跟随运行时事件实时更新。

活动关注 会标出进行中、未完成或失败的自动任务。点击其中一项可以直接打开对应状态或设置字段。

状态与设置

设置 控制自动任务是否启用以及运行参数。状态 记录当天任务进度，通常由程序维护；只有在人工执行过任务或状态不同步时才需要手动修改。

会话维护

会话有效时可以点击 更新会话 延长登录状态。需要重新扫码或重新登录时，先登出账号，再清除会话。

排查问题

如果命令长时间等待响应，先看卡片上的等待数量，再查看控制台或 logs/combined.log 中的 command.failed、command.processError 和 scheduler.response.timeout。
